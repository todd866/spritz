and await final recognition, maximum 5 seconds. Wait for Listening before
speaking. Escape, another key/chord, app/focus change, sleep, session resignation,
audio reconfiguration, lost event tap and pause cancel. Recording has a 60-second
limit. Re-hold cancels the previous session. No result inserts after cancellation.

following a permission dialog. Hold again after approving. Unsupported on-device
recognition produces a visible menu status, never a cloud fallback.

nonsecure AX element. A bounded actual-focus lookup checks again before posting.

not delivery confirmations. speechFocusRejected is separate from recognizer errors.

Local telemetry: ~/Library/Application Support/Spritz/telemetry.json.
UTC daily counts, 90-day retention; optional duration count/sum/max only.
speechStart durations measure preparation; speechFinish durations measure release
to final result. No transcript, audio, keystrokes, search text, app IDs, URLs or
free-form errors. Debounced serial atomic writes, flush on normal termination.
Malformed/unknown-schema files are preserved and flagged rather than overwritten.
Upstream telemetry remains disabled. Existing emoji history is separate.
